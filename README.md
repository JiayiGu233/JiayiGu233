# Hi, I'm Sarah Gu

Computer Engineering student at the University of Waterloo building backend systems, developer tools, and reliable low-level software.

I enjoy turning technical problems into practical products, from job-search workflows and review tools to concurrent systems and graph algorithms.

## Featured projects

### [Application Tracker](https://github.com/JiayiGu233/application-tracker)

Java 21 and Spring Boot REST API for managing job applications. It includes validated stage transitions, optimistic locking, transactional event history, pagination, integration tests, Docker packaging, and CI.

`Java` `Spring Boot` `JPA` `H2` `Docker`

### [Algorithm Review Deck](https://github.com/JiayiGu233/algorithm-review-deck)

Full-stack interview-practice dashboard for tracking solved problems, rating mastery, scheduling reviews, and storing progress. Built from my LeetCode and NeetCode review workflow.

`TypeScript` `React` `Cloudflare D1` `Drizzle`

### Job Radar

Private collaborative job-discovery workspace that aggregates openings, removes duplicates, ranks matches, and organizes application preparation. I contributed application packaging and product improvement recommendations.

`Python` `FastAPI` `SQLite` `Browser Extension`

### [Traffic Route Planner](https://github.com/JiayiGu233/traffic-route-planner)

C++17 road-network engine using Dijkstra's algorithm for minimum travel-time routing, with dynamic traffic adjustments and graph updates.

`C++17` `Graphs` `Priority Queues`
